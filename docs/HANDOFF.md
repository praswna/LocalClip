# LocalClip 인수인계

## 현재 상태
- 2026-09-16: 빈 `praswna/LocalClip` 저장소에서 UI 우선 구현.
- Electron / React / TypeScript / Vite, 한국어 밝은 테마 3열 화면.
- Windows에서 더블클릭 실행할 수 있는 `LocalClip.bat` 추가.
- BAT는 Codex 번들 런타임을 사용할 때 Node 실행 경로를 PATH에 추가하고, 중단된 의존성 설치를 자동 복구한다.
- `desktop`과 `package:win` 스크립트는 전역 pnpm에 의존하지 않도록 로컬 TypeScript/Vite 실행 파일을 Node로 직접 호출한다.
- 사용자 피드백에 따라 장식 문구·중복 상태 정보·카드 설명을 줄이고, 개발용 화면 상태 선택을 설정으로 이동한 미니멀 UI로 정리했다.
- 기본 테마를 다크로 변경하고 앱 제목과 안내 문구에서 감성형 부제목을 제거했다.
- 전역 단축키: `1~4`는 등록 순서상 첫 네 게시판, `Q/E`는 피드 순환, `A/D`는 글 순환. 입력·선택·팝업에서는 단축키를 비활성화한다.
- 게시판 추가 진입점을 3개에서 상단 버튼 1개로 통합했다. 장식성 배지·콜아웃·하단 상태바를 제거하고 목록/본문 글자 크기와 대비를 높였다.
- 사이드바와 콘텐츠 사이의 외부 여백을 제거하고, 헤더·메뉴·도구막대·목록·본문 패딩을 축소한 edge-to-edge 레이아웃으로 변경했다.
- 샘플 12개, 프로젝트 자체 SVG 일러스트 3개. 원격 이미지·웹폰트 의존성 없음.
- 검색·필터·정렬·읽음·샘플 보관/취소·구독 등록·설정·상태 미리보기 구현.
- 데모 상태는 localStorage에 보관. 저장소 인터페이스는 `src/data/types.ts`.
- 원문 버튼은 가상 글의 실제 원문 대신 출처 게시판을 연다.
- 원격 사이트 창은 preload 없음, sandbox와 contextIsolation 적용. AAGAG만 공개 목록 수집과 같은 격리 세션을 재사용한다.
- Electron 앱에서 저장 위치를 선택하고 실제 글별 폴더를 생성한다. `index.html`, `metadata.json`, `images/`를 저장하며 현재 샘플 이미지는 앱 번들에서 복사한다.
- 보관함 상태는 선택한 저장 루트의 `index.json`에서 복원한다. 보관함 삭제 시 해당 글 폴더와 인덱스 항목을 함께 삭제한다.
- AAGAG `/issue/` 공개 목록을 Electron의 격리된 영구 Chromium 세션(`persist:localclip-aagag`)으로 실제 수집한다. 앱 시작 및 새로고침 시 최대 80개의 제목·글 ID·상대 시각·용량·조회 정보와 원문 URL을 갱신한다.
- AAGAG의 일반 HTTP 요청은 Cloudflare 403을 반환하므로 렌더링된 DOM에서 읽는다. 수집 창에는 preload와 Node 권한이 없고, 실패하면 기존 목록을 유지하며 오류를 표시한다.
- AAGAG 실제 목록의 상세 화면은 목록 메타데이터만 표시하며, 본문·이미지·동영상 수집은 아직 연결하지 않았다. 원문 열기는 개별 글 URL을 사용한다.

## 로컬 보관 인터페이스
- Preload API: `getArchiveInfo`, `chooseArchiveFolder`, `savePost`, `deletePost`.
- 저장 루트: 사용자가 선택한 폴더 아래 `LocalClip/`.
- 글 경로: `LocalClip/{source}/{postId}/`.
- `metadata.json`: 원문 URL, 제목, 작성자, 분류, 작성/저장 시각, 이미지 상대 경로, `videos` 링크 배열.
- `index.html`: 스크립트 없는 독립 오프라인 문서. 모든 본문 문자열을 HTML escape 처리한다.
- IPC는 메인 프레임 송신자를 검사하고 경로 세그먼트를 정규화하며 저장 루트 밖 경로를 거부한다.

## 검증
- TypeScript 및 Vite 프로덕션 빌드 성공.
- 저장소 단위 테스트 4개 성공.
- Playwright 브라우저 E2E 6개 성공: 등록→읽기→보관→본문 검색→재실행→삭제, 필터·정렬·설정 유지, 상태 미리보기, 키보드 초점, 900/780/390px 화면, 데모 시작 시 외부 요청 없음.
- 실제 Electron 실행 검사 성공: AAGAG 실제 공개 목록 수집, 샌드박스와 Node 격리, 위험 URL 거부, 앱 완전 종료·재실행 후 샘플 보관 상태 유지.

## 의도적인 제한
- 실제 로그인, AAGAG 본문·이미지 다운로드, 인벤 수집, SQLite는 미구현.
- 구독을 추가하면 등록 상태는 유지되지만 실제 글은 수집하지 않는다.
- 최초 제공 샘플은 기본 두 게시판에만 연결되어 있다.
- 안 읽은 글에서 읽기를 시작하면 현재 선택 글은 다른 글을 선택하거나 화면을 나갈 때까지 유지된다.
- UI의 저장은 샘플 보관 상태 저장이며 다운로드가 아니다.
- 데모 글의 시간은 앱 시작 시 상대 시간으로 생성된다.
