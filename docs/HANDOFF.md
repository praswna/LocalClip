# LocalClip 인수인계

## 현재 상태
- 2026-09-16: 빈 `praswna/LocalClip` 저장소에서 UI 우선 구현.
- Electron / React / TypeScript / Vite, 한국어 밝은 테마 3열 화면.
- Windows에서 더블클릭 실행할 수 있는 `LocalClip.bat` 추가.
- BAT는 Codex 번들 런타임을 사용할 때 Node 실행 경로를 PATH에 추가하고, 중단된 의존성 설치를 자동 복구한다.
- 샘플 12개, 프로젝트 자체 SVG 일러스트 3개. 원격 이미지·웹폰트 의존성 없음.
- 검색·필터·정렬·읽음·샘플 보관/취소·구독 등록·설정·상태 미리보기 구현.
- 데모 상태는 localStorage에 보관. 저장소 인터페이스는 `src/data/types.ts`.
- 원문 버튼은 가상 글의 실제 원문 대신 출처 게시판을 연다.
- 원격 사이트 창은 임시 세션, preload 없음, sandbox와 contextIsolation 적용.

## 검증
- TypeScript 및 Vite 프로덕션 빌드 성공.
- 저장소 단위 테스트 4개 성공.
- Playwright 브라우저 E2E 5개 성공: 등록→읽기→보관→본문 검색→재실행→삭제, 필터·정렬·설정 유지, 상태 미리보기, 키보드 초점, 900/780/390px 화면, 데모 시작 시 외부 요청 없음.
- 실제 Electron 실행 검사 성공: 샌드박스와 Node 격리, 위험 URL 거부, 앱 완전 종료·재실행 후 샘플 보관 상태 유지.

## 의도적인 제한
- 실제 로그인, 수집, 본문·이미지 다운로드, SQLite, 폴더 선택은 미구현.
- 구독을 추가하면 등록 상태는 유지되지만 실제 글은 수집하지 않는다.
- 최초 제공 샘플은 기본 두 게시판에만 연결되어 있다.
- 안 읽은 글에서 읽기를 시작하면 현재 선택 글은 다른 글을 선택하거나 화면을 나갈 때까지 유지된다.
- UI의 저장은 샘플 보관 상태 저장이며 다운로드가 아니다.
- 데모 글의 시간은 앱 시작 시 상대 시간으로 생성된다.
