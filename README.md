# LocalClip

여러 게시판의 글을 한곳에서 읽고, 마음에 드는 글을 내 PC에 간직하는 Windows 데스크톱 앱입니다.

**v0.1은 UI 데모입니다.** 실제 게시글 수집, 로그인 유지, 본문·이미지 다운로드, SQLite 연동은 구현하지 않았습니다. 표시되는 게시글은 가상의 샘플이며 일러스트는 프로젝트에 포함되어 있습니다. GPT API나 서버가 필요하지 않습니다.

## 실행

Node.js 22.12 이상과 pnpm 11을 사용합니다. 개발 환경에서 검증한 버전은 Node.js 24, pnpm 11.19입니다.

```sh
pnpm install
pnpm dev          # 브라우저 UI: http://127.0.0.1:5173
pnpm desktop      # 프로덕션 빌드 후 Electron 실행
```

Windows 포터블 실행 파일을 만들려면 `pnpm package:win`을 실행합니다. 결과는 `release/`에 생성됩니다. 서명되지 않은 개인 개발 빌드입니다.

## 체험할 수 있는 기능

- 전체 글 / 안 읽은 글 / 로컬 보관함 / 게시판별 탐색
- 제목·본문 검색, 게시판 필터, 최신순·오래된순 정렬
- 글 상세 보기, 읽음 상태 변경, 목록 전체 읽음 처리
- 샘플 보관·보관 취소·삭제 확인과 재실행 후 상태 유지
- 게시판 이름·HTTPS 주소 등록, 중복 확인, 미지원 사이트 안내
- 갱신 간격 설정과 샘플 새로고침
- 하단 선택 메뉴에서 빈 목록·로딩·인증 만료·부분 저장 상태 미리보기
- 좁은 창에서는 목록/상세 화면 전환, 키보드 모달 탐색 및 Escape 닫기

인벤과 AAGAG 주소는 유형을 인식하지만 추가한 게시판의 실제 글은 가져오지 않습니다. `원문 열기`는 가상 글에 해당하는 실제 원문이 없으므로 **출처 게시판**을 엽니다. Electron에서는 권한이 격리된 임시 사이트 창, 브라우저 미리보기에서는 새 탭을 사용합니다. 이 창은 로그인 유지 기능이 아닙니다.

## 로컬 데이터

데모에서는 `localStorage`의 `localclip.demo.v1` 키에 구독 주소, 읽음 상태, 샘플 보관 상태, 설정만 저장합니다. 실제 게시글이나 로그인 정보를 수집하지 않습니다. Electron의 저장 위치는 기본 `app.getPath('userData')` 하위 Chromium 저장 영역입니다. 브라우저 미리보기 데이터와 Electron 데이터는 별개입니다.

샘플 본문·이미지는 앱에 번들되어 오프라인에서도 표시되며, 보관 버튼은 다운로드를 수행하지 않습니다. 폴더 선택·로그인 버튼은 ‘연결 예정’으로 비활성화되어 있습니다. 창을 닫으면 앱과 갱신 타이머가 종료됩니다.

## 검증

```sh
pnpm build
pnpm test
pnpm test:e2e       # Windows에 설치된 Microsoft Edge 사용
pnpm test:desktop   # build 결과 필요; 실제 Electron 실행/종료/재시작
```

E2E는 게시판 추가 → 읽기 → 보관 → 본문 검색 → 새로고침 후 유지 → 삭제 흐름, 설정 유지, 오류 예시, 작은 화면, 키보드 초점, 데모 시작 시 외부 요청 없음 등을 검사합니다. 테스트 데이터와 화면 캡처는 Git에서 제외되는 `test-results/`에 생성됩니다.

## 구조와 이어서 작업하기

- `src/data/`: 공통 타입, 샘플 데이터, 저장소 인터페이스 및 검증
- `src/App.tsx`, `src/styles.css`: 한국어 UI와 로컬 데모 동작
- `electron/`: 최소 권한 앱 창과 제한된 출처 열기 IPC
- `tests/`, `scripts/`: 브라우저 E2E와 Electron 재시작 검사
